# Loan Default Analysis

Exploratory data analysis of a loan dataset to understand which borrower and loan characteristics are associated with default.

## Problem Statement

Lenders lose money when borrowers fail to repay. This project analyzes historical loan data to find patterns linked to default, so that high-risk applicants can be identified earlier.

**Key questions:**
1. What share of loans end in default?
2. Which factors (income, loan amount, credit history, employment, etc.) are most associated with default?
3. How do default rates differ across borrower segments?
